# guess-guess

用尽量少的次数打中文语义猜词（输入词，返回 0～100% 相关度，100% 即答案）。

仓库里是一份可直接贴进新 chat 的助手提示词，外加页面控制台注入脚本：助手出词，你在游戏页跑脚本，把 `COPY_ME` 贴回去进入下一轮。

## 怎么用

在本仓库开 Cursor chat 即可：`.cursor/rules/guess-word-assistant.mdc` 会自动按提示词开局，不必再贴全文。游戏页跑脚本、把 `COPY_ME` 贴回 chat，流程不变。

在别的 AI 里：

1. 打开游戏页面，再开一个新的 AI chat。
2. 把 [`prompts/guess-word-assistant.md`](prompts/guess-word-assistant.md) 全文贴进 chat。
3. 第一轮会给出 8 个互斥探针和完整 `guessWord` 注入脚本。把脚本贴到页面控制台执行。
4. 控制台打印 `COPY_ME` 后，原样贴回 chat。之后每轮只执行一行 `guessWord([...])`，不要重复贴函数体。
5. 页面刷新、报 `guessWord is not defined`、或贴回内容显示「已猜 0 次」时，再要一次完整注入。

## 脚本约定

- 每秒猜一次；命中「访问过快」则等 3 秒重试同一个词。
- 提交按钮页文案是「猜 测」，脚本会去掉空白再匹配「猜测」。
- 用成功条「X是正确的答案！」或分数 `>= 100` 判定命中；帮助区「猜盐」不算。
- 定坐标系 8 个词必须跑完（`guessWord(words, false)`）。之后某词刷新最高分且首次跨过 70、或比上一最高分高出 ≥10 且自身 ≥70 时，会丢掉本轮剩余词并立刻交回 `COPY_ME`。

## 提示词里的阶段

以本局全部 `ROUND` 最高分为准：

| 阶段 | 条件 | 本轮词数 |
| --- | --- | --- |
| 定坐标系 | 尚无分数 | 8 |
| 拉二级轴 | 最高分 &lt; 50 | 6 |
| 收窄 | 50–69 | 6 |
| 收口 | 70–89 且未同簇饱和 | 4 |
| 跳层 | 同簇全高无满分，或连续两轮最高分提升 &lt; 3 | 4 |
| 临门 | ≥ 90 | 3 |
