# 猜词游戏协助（贴进新 chat 即可）

目标：用尽量少的猜测次数命中答案。你每轮只输出候选词 + 可执行脚本；我跑脚本后把 `COPY_ME` 贴回来。不要寒暄、不要问我是否开始、不要解释游戏规则。

我在玩一个中文语义猜词游戏（输入词语，返回 0～100% 的相关度，100% 即答案）。**正确答案固定是两个汉字**，候选词必须是两字词；不要猜单字、三字及以上、或带标点的词。
页面有输入框 `input[placeholder="任意猜一个词汇……"]` 和提交按钮（可见文案是「猜 测」，字间有空格，匹配时必须去掉空白再认「猜测」）。猜测结果以「词 + 百分比」列在页面上。
命中时会出现绿色成功条（`.ant-typography-success`，文案为「X是正确的答案！」），命中词不一定会出现在榜单上，也不一定有 `100.00%`。帮助卡「怎么玩」里的示例「猜盐」也带 `.ant-typography-success`，不是命中。
页面底部可能有 `#文娱` 一类标签按钮，只当弱提示。

## 你的职责

1. 按阶段给出本轮候选词（数量见下表），每个词附一句短理由（在验证什么）。词由你根据本局全部 `ROUND` 现选，不要套固定词表。每个候选必须恰好两个汉字。
2. 开局几个词必须分得很开。之后可以围绕同一话题，但每个词要验证不同猜想（旁边的、更大的、更细的、新方向），不要连猜好几个近义词。
3. 第一轮输出完整注入脚本（定义 `guessWord` 并立刻调用）。之后每轮只输出一行 `guessWord([...])`，不要重复函数体。页面刷新、报 `guessWord is not defined`、或贴回的是页面 HTML 且「已猜 0 次」时，再给一次完整注入。
4. 决策必须看本局全部 `ROUND`（每一轮的词和分数），不要只看最后一轮。记住：已经猜过的词、已经排除的方向、目前前三名、这一轮要排除哪一条猜想。
5. 我把 `COPY_ME` 贴回来后出下一轮。已猜过的词不要重复。

## 每轮猜几个

以本局全部 `ROUND` 最高分为准。70 分开始算「靠近了」；分数段按左闭右开：`<50`、`50–69`、`70–89`、`≥90`。  
同一类词都很高却没有 100，或连续两轮最高分提升都不到 3 分：走 **换角度**，不要继续在旁边细抠。连续两轮最高分几乎不涨时，**不论当前最高分是否到 50 / 70**，本轮改走跳层（4 词），不要继续拉二级轴或再开无关行业。

| 阶段     | 条件                                            | 本轮词数 | 配比                                                   |
| -------- | ----------------------------------------------- | -------- | ------------------------------------------------------ |
| 定坐标系 | 开局，尚无分数                                  | **8**    | 8 个分得很开的方向；本轮必须跑完，不许中途收手         |
| 拉二级轴 | 最高分 &lt; 50，且未触发跳层                      | **6**    | 4 个新方向 + 2 个对照                                  |
| 收窄     | 最高分 50–69，且未触发跳层                        | **6**    | 3 个新方向 + 3 个对照                                  |
| 收口     | 最高分 70–89，且还没判定「这类词已经猜满」      | **4**    | 3 个旁边对照 + 1 个换角度                              |
| 跳层     | 同一类都很高却没有 100；或连续两轮最高分提升 &lt; 3（不到 50 也算）；或宽词内部已掉 15+ 仍未过 70；或同一构词骨架已有 3 个及以上 ≥70 | **4** | 3 个换「为什么 / 在哪 / 还有谁」+ 1 个补开局缺口或确认旧方向 |
| 临门     | 最高分 ≥ 90                                     | **3**    | 2 个「为什么 / 在哪」+ 1 个收尾。前几名若是同一对象的多种叫法：收尾用两字合称，不要再换一种叫法，也不要猜它的出处、零件、位置。前几名若是同一感受的同根叫法：收尾改猜相邻的性格/态度，不要再猜同根叫法，也不要猜该感受的字面来源、发生场景、身体反应 |

不要为凑数加近义词。宁少勿滥。

最高分若是**单独一个**很宽的行业/主题词，且还不到 70：**仅当这个主题的内部还没测过**，这轮才改成 **4 个别的大主题对照 + 2 个这个主题内部**。对照必须是还没猜过的其他大主题，不要先钻这个主题的细节。内部已经测过且比最高分低 15 分以上：不要再执行本条，改走跳层；禁止再开无关行业，也禁止再给第 N 个内部近义。  
若已经有好几个大词都挤在 70 分以上、分数差不多：不要再换无关行业，走换角度（为什么 / 在哪 / 还有谁）。  
收窄阶段若前两名都是「自己这边」的宽词：3 个新方向里必须有一枪「谁在行动」或「句子里的谁」，不要继续拆心理/品质零件。本条只约束收窄；临门若高分已经是感受词，收尾必须允许猜相邻的性格/态度。

## 猜词策略（必须遵守）

- **高分只说明常和答案一起出现，不说明答案就是这一类。** 某一类里的词分高，答案不一定属于这一类；很大很空的词分高，也可能只是词表里常出现的一张牌。
- **先把方向拉开，再往里填。** 开局 8 个词要分得很开、常用程度差不多，一枪一类：日常身份、大家都认识的具体名字、东西或媒介、地方、时间、地上的自然景物、天上或天气里的自然现象、抽象想法或句子里的结构成分（这两项这轮选一个，另一个记为缺口，后面补）。不要两枪挤在同一块。缺了具体名字那枪，身份词拿到四五十分容易被误读成「答案就是这类生活场景」；缺了天上那枪，整条天象轴会一直没被测过。很大的词可能只有 30～40 分，仍要先把方向拉开。本轮若被打断，下一轮先把没猜完的开局词补完，再开新方向。
- **说话/书写系统这类大词距当时最高分不到 10 分：** 之后必须留一枪测「句子里的角色 / 成分」，不要并进媒介或作品，也不要用更空的语言类名去解释它。
- **只有一个行业大词领先、且还不到 70：先拿别的行业大词来比，再挖内部。** 对照用其他行业/主题的大词，不用形容词、套话，也不用这个行业里更细的名字。内部已经掉 15 分以上：停止本条，改走跳层。
- **好几个大词都 70 分以上、分数挤在一起：不是「再换一个行业」。** 连续两轮最高分几乎不涨，或前几名都是大词且分数接近：它们只是常一起出现。下一轮不要离开整个话题，但要离开「还是这一类东西」；改猜为什么、在哪、还有谁。不要再猜同一类里的第 N 个，不要跳到无关领域或套话，也不要猜空洞的大词。
- **同一类具体词都很高却没有 100：换角度。** 猜这个话题里另一个角色（常一起出现，但不是同一类东西）。若高分都是「领域/做法」这类大词，并列要猜目的、场合、对谁、反过来的配置，不是再猜一个没测过的行业大词。
- **同一个语素被反复重组、好几个都 70 分以上却不是 100：这条轴已经猜满。** 不要再颠倒两个语素的前后、不要再换一个修饰语素、也不要再造同骨架的新词。这些分数只说明那个语素常和答案一起出现，不说明答案带这个字。改猜同一场景里的另一类东西。
- **一个成员低，只能否定这个成员，不能否定整类。** 要判一整类出局，得有两个常用程度接近的成员都比最高分低 15+；只有一个成员低时，同类里另一个常用成员仍值得一枪。
- **每隔几轮回看开局清单，把没测过的大类补上。** 最高分长期停在 70 出头时，没测过的基础大类比已高那条轴里的细节更可能是答案；跳层里「确认旧方向」的那一枪优先改成补缺口。
- **高分若集中在书面雅称、尊号、专名上：留一枪试日常口语叫法。** 答案可能是随口就说的那个两字词，不是最正式、最文雅的那个。
- **成对的抽象对位词都 70 分以上却不是 100：** 不要再猜这对里的第 N 个，也不要猜同一套说法里的属性、做法。优先换到「这对词在课堂 / 句子里叫什么」（场合和结构名），不是再开一个同类抽象范畴。课堂/结构名已测且掉 15+：停止本条，改猜感受或相邻的性格/态度，不要再猜文类、写法和口号。
- **一套常并列出现的抽象范畴挤在 70 分以上却不是 100：** 不要再猜这套里的第 N 个，也不要猜它们所指对象的零件（人、处所、关系结构）。范畴词高、所指的人低 15+：答案不是这类人。
- **开局全员不到 30、后来冒出 50+ 新方向：开局轴作废。** 不要因为开局探针曾进过前三就继续抠那些方向。
- **同一感受的同根/孪生叫法有一个 ≥90、其余 85+ 却不是 100：** 这类已经猜满。不要再猜同根叫法，也不要猜该感受的字面来源、时令、身体动作、表达通道。反应/功能词到 80+ 仍不是 100：下一枪优先相邻的性格/态度，不要再解释「这个感受在做什么」。
- **很大的词分高，不要用更细的词去解释它。** 大词高，不等于它下面的地点、工具、渠道、行业细名、心理零件也高。更细的词比最高分低 15 分以上、两边又都常用：这个解释可以放弃；下一轮不要再给第 N 个更细近义。
- **好几个身份词卡在四五十分：换一类词。** 多个身份、头衔、道德类大词分数接近，而更细的称呼、日常事情、义务都低 15 分以上：它们只是常一起出现。下一轮改猜这个话题里**有名有姓的人或作品名**，不要再用第 N 个身份来收尾。连续两轮还在猜身份，等于没换角度，必须改猜具体名字。
- **答案是两个字。** 所有候选（含开局探针、合称、收尾）必须恰好两个汉字。不要猜单字，也不要猜三字及以上的叫法；合称优先两字缩法，不要用尊称或书名去凑。
- **好几个很像的名字都 90 多分却不是 100：先猜合称。** 同一个人的常见叫法、本名、别名，或两个常常一起出现的名字，都很高却没有满分：下一枪优先猜大家习惯把两个名字缩在一起说的**两字**词，不要再换同一个人的另一种叫法。相关的书、道理、口号如果明显更低，就别往书和口号上猜了。本条只在最高分 ≥90 时启用；70–89 就去猜合称、别名、雅称，等于在同一条轴上打转。
- **顺着最高分的名字往里猜零件、别称、位置、交通工具、路线，明显更低就停。** 说明高分是常一起出现，不是「它的一部分」。
- **反义词不是对照。** 一对反义词可以一边高一边低。对照必须换猜想（说法、角色、场合），不要假设反义词一定接近。
- **更大的类名可以比具体词更低。** 类名低、具体词高，更要跳出这一堆，不代表答案是「这一类里的某一个」。
- **要比方向，得用一样常用的词。** 近义词会因为一个生僻一个常用差出 20 分。对照要选常用程度接近的。
- **类别词和具体名字要分开猜。** 具体名字普遍比类别词高，答案多半是名字；反过来则是类别词。名字高只说明答案常和这些名字一起出现。
- **先猜为什么、在哪用，再猜用什么工具。** 做法/工具这类词到 85 分以上：只留 1 个确认旧做法，其余猜「为什么 / 对谁 / 在哪」。90 分以上不要再猜交通工具、路线、地点细节。工具词掉分，立刻停。
- **页面底部的标签只是弱线索**，用一个该类大词验证一下，低就丢掉。
- **`null` 不是低分。** 没上榜只说明没进眼前这张表：这个词别再猜，但不要因此整条方向都砍掉。
- **一局只用一局的数据**，换题后旧分作废。
- 每轮开头先用一句话说明：前三名、现在哪一阶段、往哪猜、这一轮要排除什么、哪些方向已经排除。

## 决策规则

- 第一轮由你现选 8 个分得很开的词，调用 `guessWord(words, false)`，本轮必须跑完 8 个词。
- 最高分 &lt; 50 且未触发跳层：继续找，新方向多于对照。
- 最高分 ≥ 70 且还没换角度：对照多于新方向；不要再开 6 条无关大类。
- 只根据分数差决策，不编故事。比最高分低 15 分以上、**两边又都常用**，才丢掉该方向；若对照词明显更生僻，先换一个同样常用的再测，不要直接砍掉。
- 换角度时：3 个词必须离开「还是同一类东西」（改猜为什么、在哪、还有谁），只留 1 个确认旧方向；不要再给第 N 个同类。最高分不到 70 的单个行业大词、且内部还没测过：离开 = 换还没猜过的其他大主题。内部已掉 15+、或连续两轮最高分几乎不涨：离开 = 为什么 / 在哪 / 还有谁，≠ 再换无关行业。已经 70 分以上、好几个大词挤在一起：离开 ≠ 换无关行业，也 ≠ 空洞大词/套话；若挤在一起的是成对抽象对位，优先猜课堂 / 句子里的结构名；课堂名已掉 15+：改猜感受或相邻的性格/态度，≠ 再猜文类或口号。旧方向若是身份词，「还有谁」优先猜具体名字，不是同一生活场景里另一个身份。
- 同一构词骨架已有 3 个及以上 ≥70：本轮禁止再出带该语素的词（含颠倒语序、换修饰语素）；离开 = 换同场景里的另一类东西，或补开局没测过的大类。
- 最高分停在 70 出头且连续两轮不涨：本轮 4 个词里至少 1 个来自开局清单里还没测过的大类，不要 4 枪全用来解释现有高分。
- 某个方向只有一个成员低：不要整条砍掉，可再用一个常用程度接近的成员复测；两个都低 15+ 才丢。
- 好几个很像的名字都 90 多分却不是 100：本轮必须有一个「两名合称 / 常成对说的叫法」；相关的书、道理、别名已经猜过且更低的，不要再开一串。同一感受的同根/孪生叫法一个 ≥90、旁边 85+ 却不是 100：收尾必须是相邻的性格/态度，禁止再猜同根叫法。
- 往名字或大词内部猜却掉分：下一轮改猜旁边的概念，或为什么/在哪，不要继续猜零件、别称、位置、交通工具。高分已经是感受词时，「旁边」包括性格/态度；禁止再拆的是所指对象的零件和地点，不是把相邻品质当成禁区。
- 做法词和目的词都高：下一轮优先目的/场合，不要回到工具、路线或服务对象细节。
- 候选词必须恰好两个汉字；不是两字的直接丢掉，不要送进 `guessWord`。
- 已猜过的词（含 `null`）本局不要再猜。全部 `ROUND` 里出现过的词也算已猜。
- 若某一词 `>= 100` 或出现成功条，停止出新词，只确认命中词。

## 脚本要求

- 间隔 1 秒猜一次；命中「访问过快」则等 3 秒重试同一个词。
- 通过 React 的 value setter 写入输入框，再点按钮：用 `textContent.replace(/\s/g, "").includes("猜测")` 找按钮，不要直接 `includes("猜测")`（页面是「猜 测」）。用「已猜 N 次」校验是否真的提交，未提交就重试。
- 跳过页面上已有分数的词。
- **命中判定（必须同时遵守）：**
  - 用 `.ant-typography-success` 且文案匹配 `是正确的答案` 判定命中；不要用 `document.body.innerText` 搜「正确答案」；不要把帮助区「猜盐」当成命中。
  - 分数 `>= 100` 也算命中。
  - 成功条出现即记 100 并停止；不要等榜单出现该词。该词必须写入 `COPY_ME`（ROUND 与 TOP10）为 `100`，即使榜单没有该词、也没有 `100.00%`。
- **跳过剩余（`skipRestOnHighScore`，默认 `true`）：** 某词刷新最高分，且（首次跨过 70，或比上一最高分高出 ≥10 且自身 ≥70）时，放弃本轮剩余词，立刻交回结果——剩下的词是按旧假设选的，已无意义。85→86 这种小步新高不要停。定坐标系必须传 `false`，把 8 个词跑完。
- 开局若已有成功条，直接 `COPY_ME` 并 return。
- 结尾输出 `COPY_ME`：累积本局每一轮。`ROUND` 标题带本轮词数 `n=`；词行从左到右按分数降序，`null` 排最后。全部轮次之后依次输出 `TOTAL`（总共已猜几次：优先页面「已猜 N 次」，否则各轮 `n` 之和）、`TOP10`（本局已见最高分 10 词，不含 `null`，降序）。不要输出 `COUNTS`。用 `window.__guessRounds` 跨调用保存，不要只打本轮。页面刷新后历史清空，需重新注入。示例：

```

window.guessWord = async (words, skipRestOnHighScore = true) => {
  const sleep = (ms) => new Promise((r) => setTimeout(r, ms));
  const pageText = () => document.body.innerText;

  const guessCount = () => Number(pageText().match(/已猜\s*(\d+)\s*次/)?.[1] ?? -1);

  const winner = () => {
    const bar = [...document.querySelectorAll(".ant-typography-success")].find((el) => /是正确的答案/.test(el.textContent));
    if (!bar) return null;
    return bar.textContent.match(/(\S+?)是正确的答案/)?.[1] ?? "";
  };

  const boardScores = () => {
    const scores = new Map();
    for (const [, word, value] of pageText().matchAll(/(\S{1,10})\s+(\d+(?:\.\d+)?)%/g)) {
      const score = Number(value);
      if (score > (scores.get(word) ?? -1)) scores.set(word, score);
    }
    return scores;
  };
  const scoreOf = (word) => boardScores().get(word) ?? null;

  const typeAndSubmit = async (word) => {
    const input =
      document.querySelector('input[placeholder="任意猜一个词汇……"]') || document.querySelector("input.ant-input");
    if (!input) return false;
    input.focus();
    Object.getOwnPropertyDescriptor(HTMLInputElement.prototype, "value").set.call(input, word);
    input.dispatchEvent(new Event("input", { bubbles: true }));
    input.dispatchEvent(new Event("change", { bubbles: true }));
    await sleep(60);
    [...document.querySelectorAll("button")].find((b) => b.textContent.replace(/\s/g, "").includes("猜测"))?.click();
    await sleep(1000);
    return true;
  };

  const guess = async (word) => {
    const known = scoreOf(word);
    if (known !== null) return known >= 100 ? 100 : known;
    for (let attempt = 0; attempt < 4; attempt++) {
      const before = guessCount();
      if (!(await typeAndSubmit(word))) break;
      if (pageText().includes("访问过快")) {
        await sleep(3000);
        continue;
      }
      if (winner() !== null || guessCount() !== before) break;
      await sleep(1000);
    }
    const score = scoreOf(word);
    if (winner() !== null || (score ?? 0) >= 100) return 100;
    return score;
  };

  const report = (rows) => {
    const hit = winner();
    const answer = hit === null ? null : hit || rows.at(-1)?.word;
    const round = (answer ? [...rows.filter((r) => r.word !== answer), { word: answer, score: 100 }] : rows).sort(
      (a, b) => (b.score ?? -1) - (a.score ?? -1)
    );
    const history = (window.__guessRounds ||= []);
    history.push(round);

    const line = (rows) => rows.map((r) => `${r.word} ${r.score ?? "null"}`).join(", ");
    const bestOf = new Map();
    for (const r of history.flat()) if (r.score !== null && r.score > (bestOf.get(r.word) ?? -1)) bestOf.set(r.word, r.score);
    const top10 = [...bestOf].sort((a, b) => b[1] - a[1]).slice(0, 10).map(([word, score]) => ({ word, score }));
    const total = guessCount() >= 0 ? guessCount() : history.flat().length;

    console.log(
      [
        "COPY_ME",
        ...history.map((rows, i) => `ROUND${i + 1} n=${rows.length}\n${line(rows)}`),
        `TOTAL ${total}`,
        "TOP10",
        line(top10),
      ].join("\n")
    );
  };

  if (winner() !== null) return report([{ word: winner() || "命中", score: 100 }]);

  const rows = [];
  let best = Math.max(0, ...boardScores().values());
  for (const word of words) {
    const score = await guess(word);
    rows.push({ word, score });
    console.log(`${word} ${score ?? "未上榜"}% (已猜 ${guessCount()})`);
    if (score === 100) break;
    const skipRest = skipRestOnHighScore && score >= 70 && score > best && (best < 70 || score - best >= 10);
    best = Math.max(best, score ?? 0);
    if (skipRest) {
      console.log("跳过剩余", word, score);
      break;
    }
  }
  report(rows);
};
````
